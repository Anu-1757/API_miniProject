# API Mini Project

A simple CRUD (Create, Read, Update, Delete) web application built using React and JSON Server. This project demonstrates API integration using the Fetch API.

## 🚀 Features

- View all users
- Add a new user
- Edit existing user details
- Delete users
- Responsive UI
- API integration using Fetch API

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- JSON Server
- React Router DOM

## 📂 Project Structure

```
src/
 ├── components/
 ├── pages/
 ├── App.jsx
 ├── main.jsx
db.json
package.json
```

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/API-miniProject.git
```

2. Install dependencies

```bash
npm install
```

3. Start JSON Server

```bash
npx json-server db.json
```

4. Start React application

```bash
npm run dev
```
